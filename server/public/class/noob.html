class

Noob.

None of your four working stats has reached 30 yet. Everyone starts here.

// what makes a Noob

Craft, Autonomy, Arsenal and Appetite are the four working stats. Below 30 none of them is strong enough to name a class. Use Claude Code for a few weeks and one of them takes over. Grind and Brains never set the class.

In the Mac menu bar panel, every class has its own colour and hat. The Noob wears a propeller beanie.

// six stages

Every creature starts as an Egg and grows with the XP you earn. Your class can change as you work; your stage only goes up.

  • Egg from Lv 1
  • Hatchling from Lv 5
  • Lil Guy from Lv 15
  • Big Guy from Lv 30
  • Gigachad from Lv 45
  • GOAT from Lv 60

// grow the rest

To grow your stats, run /pet learn: five lessons per stat that tick themselves from your logs.

// what's yours?
