    // how it works

    1. Install in Claude Code:
      • /plugin marketplace add Spider333/cclevel
      • /plugin install cclevel@cclevel
    2. Meet your creature with /pet. It runs on your machine and sends nothing to the board.
    3. Join the board with /pet join the leaderboard. It shows you exactly what it would send and asks first.
    4. Bring friends with /pet start a group. You get an invite link; up to 25 friends compare in private.

    Everything the board gets from you

    {
  "v": 1,
  "xp": 21480,
  "xp_days": 94,
  "stats": { "grind": 55, "appetite": 45, "arsenal": 50,
             "brains": 70, "autonomy": 25, "craft": 55 },
  "badges": ["first_hook", "first_skill", "streak_7"]
}

    Plus a random key made on your machine, so your check-ins land on the same row. The board keeps only its hash.

    Only if you ask for them: a private group's invite code (the board keeps only its hash) and the GitHub login for the badge.

    Never sent: your name, e-mail, prompts, code, file paths, or the names of your projects and skills. The board stores no IP address. Your creature's name is made up from a random key on your machine.

    Don't trust us, read it: the code and every field the board stores.

    // the fine print

    How ranking works

    Season is the XP a creature earned this month; All-time is everything since it joined. Both count only daily XP the board credited itself, at most 550 per active day, without badge XP. Level is shown as each owner's own scanner reports it, and does not set the order. Equal XP shares a place. The top 1,000 are listed; below them the board publishes the XP needed for each band, and --rank works out your place on your own machine. Lists are rebuilt every six hours.

    What sus means

    A creature with at least 14 witnessed days of which 80% or more were credited at the full 550 XP. It changes nothing else: not the place, not the XP, not the listing. It cannot catch a script that claims a little less, and does not pretend to.

    The GitHub badge

    Optional. ✓ login · 123 means the owner proved that GitHub account is theirs, and 123 of its public commits carry Claude Code's co-author line. It never changes a place or XP. The count sees public default branches only, counts a squash merge once, and cannot tell a hand-typed line from a real one.

    Privacy

    The board holds no account, e-mail address or IP address. A creature is its score (nine numbers and a list of badges), a generated name, the hash of a random token and a few dates and counters. It appears here only while its owner keeps the world ranking on; --world off and --leave take it off at once. Totals count every creature with check-ins on two days, listed or not, and appear only from 100 creatures. PRIVACY.md lists every field.
