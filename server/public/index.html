    Is it anonymous?

    Almost. It's pseudonymous: no account, no name, no e-mail, and the board never stores your IP address. Your creature is a made-up name tied to a random key on your machine. The catch: if you post your card or creature name publicly, or turn on the GitHub badge, people can match it to you.

    Can people cheat?

    On their own card, yes: it's self-reported and for fun, not a credential. The board limits what cheating buys. It ranks only XP it watched you earn, at most 550 a day, and marks suspicious patterns as sus.

    Does it slow down Claude Code or run in the background?

    No. There are no hooks and no background process. It runs only when you call /pet.

    Does it read my prompts?

    It reads your Claude Code folder to count things: days, tokens, tools used, prompt timestamps. Nothing from your prompts, code or file names is printed, stored or sent.

    Why are invite links shown in full inside Claude Code?

    So you can copy one. A link shown or pasted in a conversation becomes part of that chat's history. It only grants a seat in that group, and you can always start a new group.

    How do I get off the board?

    Ask /pet to leave the board. Your row is deleted at once; the database host's backups age out after up to 30 days (7 on the free plan). More in the fine print.
