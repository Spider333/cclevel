Someone wants to compare Claude Code setups with you. Measure it. Compare it. Stay nameless.

CC level turns your Claude Code setup into a creature with a level and six stats. A private group of up to 25 friends sees each other's numbers. Nobody else does.

// join in three steps

  1. Install in Claude Code:
    • /plugin marketplace add Spider333/cclevel
    • /plugin install cclevel@cclevel
    Already have CC level? Update it first: /plugin → Marketplaces → cclevel → Update marketplace, then /reload-plugins. Pick Enable auto-update there too, and new features arrive on their own.
  2. Paste this into Claude Code:
    • /pet join
  3. Say yes once. It shows exactly what it sends, then joins the board and the group together.

What your group sees

Each member's generated name, level, XP since joining, season XP, six stats and sus mark. No names, prompts, code or e-mail ever leave your machine. Like any join, joining the board this way also lists your creature on the world board and checks in once a day; /pet take me off the world list keeps it private to the group, and /pet leave opts out of everything.

Anyone with this link can join, up to 25 members. If it leaks, start a new group with /pet start a group.
